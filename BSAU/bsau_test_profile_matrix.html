Run first. Pure software test — no hardware dependencies beyond UART.

Alternating 0xAAA/0x555, 13-bit overflow, raw byte verify

Pass criteria
All sub-tests show [PASS], summary shows 0 FAIL

Terminal

115200 baud

Duration

2. TEST_NRF_LOG — deep radio self-test

Validates SPI chain, register config, power cycle, and RF state machine.

LOG on CSV off NRF module required CPCU optional
What runs
200 ms POR delay → NRF_Init with retry
NRF_Test_All: SPI loopback, register audit, address, FIFO, power cycle, TX
Runtime: TX pings every 150 ms + health checks (every 20) + stress cycles (every 100)
Without CPCU: MAX_RT on every TX — still PASS (RF state machine ran)
With CPCU in RX mode: TX_DS = ACK received = live link confirmed
Pass criteria
NRF_Test_All: 6 PASS, 0 FAIL · Health/stress checks: all PASS
TX pings: PASS (TX_DS or MAX_RT) · No TX_TIMEOUT

Terminal

115200 baud

Duration

run ≥ 2 min

3. TEST_ADC_CSV — binary ADC stream

Raw ADC pipeline validation via SerialPlot. Binary format — not human-readable.

LOG off CSV on CPCU not needed
What runs
ADC + DMA pipeline: TIM6 → 7-ch scan → DMA circular → snapshot
Binary frame: [seq_lo][seq_hi][21 × uint16 LE] = 44 bytes per frame
LED toggles at DMA rate (~667 Hz)
Pass criteria in SerialPlot
Sync counter (ch 0): increments by 1, no gaps = no dropped frames
ADC channels: ~2048 noise floor (floating) or injected signal waveform

Tool

SerialPlot

Channels

22, uint16 LE

4. TEST_CSV — ASCII ADC capture

Human-readable ADC pipeline test. Same data as ADC_CSV, easier to inspect.

LOG off CSV on CPCU not needed
What runs
Same ADC/DMA pipeline as ADC_CSV
CSV line: seq, 3×6 EMG channels, averaged battery, drop counter
Header line emitted at boot for column identification
Pass criteria
seq increments without gaps · batt stable (~1860 at 3.0V)
drop column stays at 0 (no DMA overruns)

Tool

terminal or SerialPlot ASCII

Columns

seq + 18 EMG + batt + drop

5. TEST_DFT_LOG — analog frequency response

Goertzel filter bank on live ADC. Requires a known-frequency signal source.

LOG on CSV off Signal gen required CPCU not needed
What runs
ADC channel 0 fed into 5-bin Goertzel (50/100/200/350/500 Hz)
Block size 512 samples, fs = 2000 Hz → report every ~256 ms
Logs per-bin magnitude, dominant frequency, concentration ratio
Pass criteria
Input frequency bin dominates · Concentration > 90% for clean sine
1 kHz input: all bins low (anti-alias LPF working)
No input: no dominant bin, low magnitudes (noise floor)

Input

sine on PA0

Verify

50, 100, 500 Hz
